# SandboxEDU 📚

แพลตฟอร์มการเรียนรู้ออนไลน์สำหรับนักเรียนระดับมัธยมศึกษา รองรับการดูวิดีโอบทเรียน ทำแบบทดสอบที่สร้างโดย AI สรุปเนื้อหาด้วย AI วิเคราะห์ทักษะ และดูเนื้อหาแบบออฟไลน์

---

## ฟีเจอร์หลัก

### 🎬 วิดีโอบทเรียน

- ดูวิดีโอบทเรียนออนไลน์ พร้อมบันทึกความคืบหน้าอัตโนมัติ
- รองรับการดูแบบ fullscreen และหมุนจอแนวนอน
- ดูต่อจากตำแหน่งที่ค้างไว้ครั้งก่อนอัตโนมัติ
- ดาวน์โหลดวิดีโอเพื่อดูแบบออฟไลน์ได้

### ✨ สรุปเนื้อหา AI

- กดปุ่ม **สรุปเนื้อหา AI** ในหน้าบทเรียน (เฉพาะผู้ที่ลงทะเบียนแล้ว)
- ระบบสรุปเนื้อหาคอร์สด้วย AI แสดงผลแบบ expand/collapse
- รองรับการโหลดใหม่ได้ทันที

### 📝 แบบทดสอบ AI

- ระบบสร้างข้อสอบอัตโนมัติจาก AI แยกตามระดับความยาก (ง่าย / ปานกลาง / ยาก)
- มีคำใบ้และคำอธิบายเฉลยรายข้อ
- บันทึกประวัติผลการสอบพร้อมกราฟแสดงพัฒนาการ
- บันทึกข้อสอบไว้ใช้งานแบบออฟไลน์อัตโนมัติ
- ล็อคแบบทดสอบสำหรับคอร์สที่ยังไม่ได้ลงทะเบียน

### 📊 วิเคราะห์ทักษะ

- วิเคราะห์จุดแข็ง-จุดอ่อนของผู้เรียนจากผลสอบเฉพาะคอร์สที่ลงทะเบียน
- แสดงผลเป็น Radar Chart ขนาด dynamic ยืดหดตามหน้าจอ
- Scale กราฟอัตโนมัติตามคะแนนจริง (ไม่ยึดติด 0-100)

### 🔥 Streak การเรียน

- แสดงจำนวนวันต่อเนื่องที่ดูวิดีโอบทเรียน (streak)
- ไอคอนไฟเปลี่ยนสีตามสถานะ — ส้ม (ดูวันนี้แล้ว) / เทา (ยังไม่ได้ดูวันนี้)

### 📥 Offline Mode

- ดาวน์โหลดวิดีโอบทเรียนเพื่อดูโดยไม่ต้องต่ออินเทอร์เน็ต
- ทำแบบทดสอบที่เคยโหลดไว้แล้วได้แบบออฟไลน์
- แสดง banner แจ้งเตือนเมื่ออยู่ในโหมดออฟไลน์
- Cache ข้อมูลโปรไฟล์และความคืบหน้าไว้ใน local storage

### 🔄 ซิงค์ข้อมูล

- ซิงค์ความคืบหน้าการดูวิดีโอและประวัติแบบทดสอบข้ามอุปกรณ์
- กดปุ่ม "ซิงค์ข้อมูล" ในหน้าตั้งค่าเพื่อ sync กับ server

### 👤 แก้ไขโปรไฟล์

- แก้ไขชื่อ, นามสกุล, ชื่อที่แสดง, รูปโปรไฟล์, ระดับชั้น, ห้องได้ทีละ field

## Tech Stack

| ส่วน       | เทคโนโลยี                                  |
| ---------- | ------------------------------------------ |
| Framework  | React Native + Expo SDK 54                 |

## การติดตั้งและรันโปรเจกต์

### ข้อกำหนด

- Node.js 18 ขึ้นไป
- npm
- Expo Go (สำหรับทดสอบบนอุปกรณ์จริง) หรือ Android/iOS Simulator

### 1. ติดตั้ง dependencies

```bash
npm install
```

### 2. ตั้งค่า Environment Variables

สร้างไฟล์ `.env` ที่ root ของโปรเจกต์:

```env
EXPO_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
EXPO_PUBLIC_API_BASE_URL=https://your-api-server.com
```

| ตัวแปร                          | คำอธิบาย                        |
| ------------------------------- | ------------------------------- |
| `EXPO_PUBLIC_SUPABASE_URL`      | URL ของ Supabase project        |
| `EXPO_PUBLIC_SUPABASE_ANON_KEY` | Anon key จาก Supabase dashboard |
| `EXPO_PUBLIC_API_BASE_URL`      | URL ของ backend API (Elysia)    |

### 3. รันแอพ

```bash
# Development (Expo Go)
npx expo start

# Android (Development Build)
npm run android

# iOS (Development Build)
npm run ios
```

สแกน QR Code ที่แสดงในเทอร์มินัลด้วยแอพ **Expo Go** บนอุปกรณ์ของคุณ

## โครงสร้างโปรเจกต์

```
app/
├── (tabs)/
│   ├── index.tsx        # หน้า Home — สถิติ, streak, ทักษะ, Quick Actions
│   ├── explore.tsx      # หน้าสำรวจ — บทเรียนและแบบทดสอบ
│   └── settings.tsx     # หน้าตั้งค่า — โปรไฟล์, ซิงค์, ออกจากระบบ
├── video/[id].tsx       # หน้าดูวิดีโอบทเรียน + สรุปเนื้อหา AI
├── quiz/[id].tsx        # หน้าเลือกระดับแบบทดสอบ (online/offline)
├── exam/[id].tsx        # หน้าสอบแบบทดสอบ (full screen, block back)
├── login.tsx            # หน้าเข้าสู่ระบบ
├── register.tsx         # หน้าสมัครสมาชิก
└── profile-edit.tsx     # หน้าแก้ไขโปรไฟล์

lib/
├── auth/                # JWT refresh, token management
├── cache/               # User profile cache
├── offline/             # Download manager
├── progress/
│   ├── quizHistory.ts   # บันทึกประวัติผลสอบ
│   ├── savedQuizzes.ts  # บันทึกข้อสอบสำหรับ offline
│   ├── streak.ts        # คำนวณ streak การดูวิดีโอต่อเนื่อง
│   └── videoProgress.ts # บันทึกความคืบหน้าการดูวิดีโอ
└── sync/                # Cross-device sync manager
```

## การใช้งานแอพ

### สมัครสมาชิก

1. เปิดแอพ → กด **สมัครสมาชิก**
2. กรอกอีเมลและรหัสผ่าน
3. ยืนยัน OTP จากอีเมล
4. กรอกข้อมูลโปรไฟล์ (ชื่อ, ชั้น, ห้อง)

### ดูบทเรียน

1. ไปที่แท็บ **สำรวจ** → เลือก **บทเรียน**
2. กดคอร์สที่ต้องการ → กด **ลงทะเบียน**
3. กด **เริ่มเรียน** เพื่อดูวิดีโอ
4. กด **เรียนจบ** เมื่อดูครบ

### สรุปเนื้อหา AI

1. เปิดหน้าบทเรียนที่ลงทะเบียนแล้ว
2. กดการ์ด **สรุปเนื้อหา AI** → กด **สรุป**
3. รอสักครู่ — ระบบจะแสดงสรุปเนื้อหาคอร์สทั้งหมด

### ทำแบบทดสอบ

1. ไปที่แท็บ **สำรวจ** → เลือก **แบบทดสอบ** หรือกดการ์ด **แบบทดสอบ** ในหน้าบทเรียน
2. เลือกระดับความยาก (ง่าย / ปานกลาง / ยาก)
3. กด **เริ่มทำแบบทดสอบ**
4. ตอบคำถาม — กด back ไม่ได้ระหว่างสอบ ยกเว้นกดปุ่มกลับในหน้าสรุปผล

### ดาวน์โหลดวิดีโอ (Offline)

1. เปิดหน้าบทเรียน → กดปุ่ม **ดาวน์โหลดวิดีโอ**
2. รอจนดาวน์โหลดเสร็จ
3. ดูได้โดยไม่ต้องต่ออินเทอร์เน็ต

### วิเคราะห์ทักษะ

1. ไปที่แท็บ **Home**
2. เลื่อนลงมาที่ส่วน **ทักษะของฉัน**
3. กดปุ่ม **วิเคราะห์ทักษะ** — ระบบจะประเมินจากผลสอบของคอร์สที่ลงทะเบียนเท่านั้น

### ซิงค์ข้อมูลข้ามอุปกรณ์

1. ไปที่แท็บ **ตั้งค่า**
2. กด **ซิงค์ข้อมูล**
